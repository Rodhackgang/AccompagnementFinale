## Présentation

Site d'accompagnement : présentation de l'offre, parcours proposés et prise de contact.

**Pourquoi ce choix.** Une page claire et rapide convertit mieux qu'une application pour un besoin de présentation.

## Ce que fait le projet

- Intégration statique responsive
- Sections de présentation et formulaire de contact
